# Smart Meal Planner

A full-stack application built to simplify weekly meal prepping and dynamically reduce household grocery waste.

## Features
- *Full CRUD Support:* Users can securely add, modify, view, and delete custom recipes.
- *Dynamic Inventory Matching (In Progress):* An algorithm that suggests meals based on what ingredients are close to expiration.
- *Weekly Scheduler:* Plan meals 7 days in advance with automatic grocery-list generation.

## Tech Stack
- *Backend:* Python
- *Frontend:* HTML5, CSS3, JavaScript (ES6)
- *Database:* SQLite3

## How To Run Locally
* init_db.py needs running first, since the .db file isn't committed

1. Clone the repository:
    bash
    git clone https://github.com/zaynah-khan/smart-meal-planner.git

2. Navigate to the project directory:
    bash
    cd smart-meal-planner   

3. Run the application:
    bash
    python app.py
